THYROVISION LAB — ГОТОВОЕ ПРИЛОЖЕНИЕ ДЛЯ WINDOWS 10/11 (64 БИТ)

БЫСТРЫЙ ЗАПУСК
1. Скачайте архив и нажмите правой кнопкой мыши → «Извлечь всё».
2. Откройте распакованную папку ThyroVision_LAB_Windows.
3. Дважды нажмите START.bat.
4. Приложение откроется в браузере. Оставьте чёрное окно запуска открытым.
   Если браузер не открылся, скопируйте адрес http://127.0.0.1:.../ из этого окна.

Ничего устанавливать не нужно: Python, модель и распознавание включены.
Colab, GPU, API-ключи, pip и интернет для расчёта не требуются.
Для завершения работы нажмите Ctrl+C в окне запуска.

КАК ПОЛУЧИТЬ РЕЗУЛЬТАТ
1. Нажмите «Выбрать файл» и загрузите PDF или фото бланка анализов.
   Поддерживаются также CSV, TSV и TXT. До 10 МБ; PDF до 5 страниц.
2. Сверьте числа, единицы и референсы с бланком; при необходимости исправьте.
3. Укажите возраст и подходящий контекст. Подтвердите проверку таблицы.
4. Нажмите «Рассчитать и разобрать».
5. Для сохранения используйте JSON или «Отчёт / PDF» → «Сохранить как PDF».

ПЕРВЫЙ ПОКАЗ БЕЗ ЛИЧНЫХ ДАННЫХ
Самый быстрый способ: кнопка «Повышенный ТТГ», подтверждение, расчёт.
Для показа загрузки откройте examples/lab-demo.pdf или examples/lab-demo.jpg.
Это синтетический учебный бланк: возраст 35 лет, ТТГ 6,5, свободный Т4 9,2.
При указанных в этом бланке референсах ожидается вывод:
«Профиль, совместимый с первичным гипотиреозом».
Не переносите референсы учебного примера на другие бланки автоматически.

ЧТО РАССЧИТЫВАЕТСЯ
Сравнение с референсами лаборатории и объяснение сочетания ТТГ со свободными
Т4/Т3. Основному профилю нужны ТТГ и свободный Т4, единицы и референсы.
При неполном бланке приложение покажет, чего не хватает.
Это исследовательский прототип, не подтверждённый диагноз и не прогноз
вероятности будущей болезни. Дозы препаратов не назначаются.
Отдельная ML-модель работает на тестовых примерах исторического датасета;
общий Т4 из него не подменяется свободным Т4 из вашего бланка.

ДАННЫЕ
Бланки обрабатываются в браузере и не отправляются серверу приложения.
Сервер доступен только на этом компьютере (127.0.0.1).
В папках data, results и research находятся датасет, результаты и методика.
Лицензия встроенного Python находится в runtime/LICENSE.txt.

ПРОВЕРКА СБОРКИ
Учебные PDF и JPG, расчёт и JSON-экспорт проверены в браузере.
Встроенный Python и локальный сервер запущены на Windows x64.
Проверены занятый порт и повторный запуск. Хеш архива Python совпал
с зафиксированной официальной SHA-256. Подробнее: docs/VERIFICATION.md.
