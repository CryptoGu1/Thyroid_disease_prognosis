ЭТО ИСХОДНЫЙ ПРОЕКТ. НУЖЕН УСТАНОВЛЕННЫЙ PYTHON.
Для запуска без установки Python используйте отдельный ThyroVision_LAB_Windows.zip.
Подробная инструкция и проверки находятся в README.md.

THYROVISION LAB — БЫСТРЫЙ ЗАПУСК НА WINDOWS

1. Скачайте архив проекта. Нажмите правой кнопкой → «Извлечь всё».
   Открывайте приложение из распакованной папки, не из окна ZIP.

2. Внутри папки найдите START_WINDOWS.bat и запустите двойным щелчком.
   Он попробует команды py -3 и python. Нужен Python 3.8 или новее.
   Если Python не найден, установите Python 3 с официальной страницы:
   https://www.python.org/downloads/windows/
   Если установщик предлагает «Add python.exe to PATH», включите этот пункт.
   После установки снова запустите START_WINDOWS.bat.

3. Приложение откроется в браузере. Оставьте окно терминала открытым.
   Если браузер не открылся, скопируйте адрес http://127.0.0.1:.../ из окна
   терминала в современный Chrome или Edge. Обычно это порт 8765;
   если он занят, приложение выберет другой свободный локальный порт.

4. Для проверки нажмите один из учебных примеров. Затем можно загрузить
   свой PDF, фото, CSV или текстовый бланк, проверить распознанные значения,
   единицы и референсы, подтвердить таблицу и нажать «Рассчитать и разобрать».
   Для проверки загрузки в комплекте есть папка dist/assets/examples.

5. «Отчёт / PDF» открывает печать браузера. В принтере выберите
   «Сохранить как PDF». JSON сохраняет структурированный результат.

6. Чтобы завершить работу, нажмите Ctrl+C в окне терминала.

ДЛЯ ОБЫЧНОГО ЗАПУСКА НЕ НУЖНЫ
PyTorch, Node.js, GPU, API-ключи и повторное обучение модели.
Все библиотеки распознавания включены в архив; локальное приложение
работает без интернета. Для установки самого Python интернет может понадобиться.

ЕСЛИ НУЖНО ЗАПУСТИТЬ ВРУЧНУЮ
Откройте терминал в распакованной папке проекта и выполните:
  py -3 research/serve.py
Если команда py недоступна:
  python research/serve.py
Для конкретного свободного порта:
  python research/serve.py --port 8766
Не открывайте dist/index.html двойным щелчком: браузерным модулям нужен
локальный HTTP-сервер, который запускают указанные команды.

ВАЖНО О РАСЧЁТЕ
Приложение сравнивает показатели с введёнными референсами лаборатории.
Числа после распознавания нужно проверить по оригинальному бланку.
Исследовательская ML-модель находится в отдельном разделе и работает
только на готовых примерах исторического датасета.
