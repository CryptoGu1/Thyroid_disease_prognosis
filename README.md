# ThyroVision LAB

Локальное приложение для разбора лабораторных анализов щитовидной железы и воспроизводимого исследования методов машинного обучения. Интерфейс и объяснения на русском языке. Бланки обрабатываются в браузере пользователя.

Проект относится к теме «Разработка методов и моделей ИИ для прогнозирования заболеваний щитовидной железы». Реализованный этап включает анализ текущего лабораторного профиля и классификацию исторических записей. Прогноз появления заболевания через определённый срок потребует отдельного исследования с продольными исходами.

## Два независимых модуля

| Модуль | Данные | Метод | Результат |
|---|---|---|---|
| Разбор бланка | ТТГ, свободные Т4/Т3, антитела, референсы лаборатории | Проверки и прозрачные правила | Отклонения и объяснение лабораторного профиля |
| Исследовательский ML | TSH, **общий** Т4 (TT4), T3 из UCI thyroid0387 | Обученный Random Forest | Класс исторической записи и оценки классификатора |

Загруженный бланк **не передаётся в ML-модель**. Общий Т4 не подменяется свободным Т4. Физические единицы исторического набора недостаточно документированы для переноса модели на современный бланк. Оценки классификатора не являются клиническим риском.

## Запуск готового Windows-комплекта

[Скачать готовую Windows-сборку в Releases](https://github.com/CryptoGu1/Thyroid_disease_prognosis/releases). Выберите вложение `ThyroVision_LAB_Windows.zip`.

1. Полностью распакуйте `ThyroVision_LAB_Windows.zip` через «Извлечь всё».
2. Откройте папку `ThyroVision_LAB_Windows` и запустите `START.bat`.
3. Дождитесь открытия браузера. Оставьте окно запуска открытым.
4. Обычно адрес: **http://127.0.0.1:8765/**. Если порт занят или недоступен, сервер выберет свободный и напечатает фактический адрес.
5. Для остановки нажмите `Ctrl+C` в окне сервера. Для повторного запуска снова откройте `START.bat`.

Комплект предназначен для Windows 10/11 **x64**. Он содержит встроенный CPython 3.14.10, модель, PDF.js и Tesseract.js с русским и английским языками. Установка Python, Node.js, pip, GPU и API-ключи для обычной работы не нужны. После распаковки обработка бланков не требует интернета.

**Готовый ZIP поставляется отдельно от исходников.** Кнопка GitHub **Code → Download ZIP** не добавляет встроенный Python. Инструкция сборки переносимого комплекта приведена ниже.

## Запуск исходников из GitHub

Нужны Python 3.8+ и современный Chrome или Edge. Сервер использует стандартную библиотеку Python, устанавливать pip-пакеты для него не требуется.

```powershell
git clone https://github.com/CryptoGu1/Thyroid_disease_prognosis.git
cd Thyroid_disease_prognosis
.\START_WINDOWS.bat
```

Без Git: скачайте **Code → Download ZIP**, распакуйте исходники и запустите `START_WINDOWS.bat`. Скрипт проверяет команды `py -3` и `python`.

Ручной запуск и параметры:

```powershell
py -3 research/serve.py
py -3 research/serve.py --no-open
py -3 research/serve.py --port 8766
py -3 research/serve.py --port 0
```

`--no-open` отключает открытие браузера, `--port 0` выбирает свободный порт. Явно заданный занятый порт вызывает ошибку. На macOS/Linux: `python3 research/serve.py` или `sh start.sh`.

Не открывайте `dist/index.html` двойным щелчком: модули, worker-файлы и модель загружаются через локальный HTTP-сервер.

## Работа с бланком

1. Выберите или перетащите **один** PDF, JPG/JPEG, PNG, WebP, BMP, CSV, TSV или TXT. До 10 МБ, PDF до пяти страниц.
2. Текстовый PDF читается напрямую. Фотография и скан распознаются локально. Для PDF доступно «Перечитать PDF как скан».
3. Сверьте название показателя, число, единицу и обе границы. Название выбирается в первом столбце. Строки можно добавлять и удалять.
4. Укажите возраст и применимые условия: беременность, тироксин, антитиреоидные препараты, острое заболевание.
5. Подтвердите сверку с бланком и нажмите «Рассчитать и разобрать».
6. Сохраните JSON или выберите «Отчёт / PDF» и принтер «Сохранить как PDF» в обычном браузере.

Референсы настоящего анализа берутся только из его бланка. При их отсутствии приложение сообщает о недостатке данных. Учебные диапазоны не подставляются автоматически.

Изменение показателя, числа, единицы, референса, возраста или контекста, добавление/удаление строки и новый импорт очищают результат и сбрасывают подтверждение. Снятие подтверждения также очищает результат.

Изменение текста единицы **не пересчитывает** число и границы: вся строка должна соответствовать одной единице оригинального бланка. Значение `<0.01` не превращается в точное число `0.01`. Обе границы референса включены, сравнение выполняется до округления.

## Демонстрация куратору за 5–7 минут

1. **Запуск:** открыть `START.bat` переносимой сборки.
2. **Бланк:** выбрать `examples/lab-demo.pdf`. В исходниках он находится в `dist/assets/examples/`.
3. **Сверка:** установить возраст 35 лет, выключить особые условия, проверить таблицу ниже и подтвердить данные.
4. **Расчёт:** показать заголовок, шкалы и величины отклонений.
5. **Контроль:** изменить число. Прежний результат и подтверждение исчезнут. Вернуть число и повторить расчёт после сверки.
6. **Сохранение:** экспортировать JSON. Для PDF открыть приложение в Chrome/Edge и использовать печать.
7. **ML:** открыть исследовательский раздел и «Пример 02». Прогноз отличается от исходной метки: реальная ошибка модели сохранена.

Для демонстрации OCR повторите сценарий с `lab-demo.jpg`. Кнопки «В референсе», «Повышенный ТТГ», «Сниженный ТТГ» содержат другие синтетические примеры.

| Показатель | Значение | Единица | Референс | Ожидаемый результат |
|---|---:|---|---|---|
| ТТГ | 6,50 | mIU/L | 0,4–4,0 | Выше на 2,5 |
| Свободный Т4 | 9,20 | pmol/L | 12–22 | Ниже на 2,8 |
| Свободный Т3 | 4,20 | pmol/L | 3,1–6,8 | В референсе |
| АТ-ТПО | 45,0 | IU/mL | 0–34 | Выше на 11 |

Ожидаемый заголовок: **«Профиль, совместимый с первичным гипотиреозом»**. Это синтетические учебные данные. Результат описывает сочетание показателей, не устанавливает окончательный диагноз.

## Исследование и результаты

Источник: [UCI Thyroid Disease](https://archive.ics.uci.edu/dataset/102/thyroid+disease), полученный через [Hugging Face](https://huggingface.co/datasets/anasmakki/thyroid_disease_dataset). Исходный CSV: 9 172 записи, 31 поле. Подробная методология: [research/METHODS.md](research/METHODS.md).

Включены записи возраста 18–100 лет без беременности и указанных видов терапии, с однозначной меткой и измеренными конечными неотрицательными TSH, TT4, T3. Пропуски исключены без заполнения. Одинаковые тройки признаков удалены **до** разбиения.

После фильтров осталось 4 417 записей, после удаления 121 повтора — 4 296. Стратифицированное разбиение 70/30, seed 42: 3 007 train и 1 289 test. Выбор модели проводится по Macro F1 в пяти стратифицированных складках **обучающей** части.

| Модель | Accuracy на test | Macro F1 на test | Средний Macro F1 на train-CV |
|---|---:|---:|---:|
| Random Forest, 64 дерева, глубина до 5 | 98,8363% | 93,7235% | 94,3198% |
| log1p + StandardScaler + LogisticRegression | 95,0349% | 84,3013% | 87,9752% |

Метрики повторно вычислены на Windows и совпали с сохранённым экспериментом. Random Forest дал 1 274 верные классификации и 15 ошибок. Высокая Accuracy связана в том числе с дисбалансом классов, поэтому приведены Macro F1 и матрица ошибок.

Строки матрицы — истинные классы, столбцы — предсказанные. Порядок: без комментария, гипотиреоидная группа, гипертиреоидная группа.

```text
1124    2    9
   0  119    0
   4    0   31
```

JavaScript-экспорт совпал с повторно обученной Python-моделью на всех **1 289** тестовых записях. Максимальная разница оценок — `8.88e-16`. При сравнении с порогами используется `Math.fround` для согласования с float32 в sklearn.

Это качество классификации исторических записей, а не точность OCR, диагностики по загруженным фотографиям или риск заболевания конкретного человека.

## Воспроизведение обучения

Рекомендуется отдельный полноценный **Python 3.12 x64**. Встроенный Python переносимой сборки предназначен для сервера, а не установки исследовательских зависимостей.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r research/requirements.txt
.\.venv\Scripts\python.exe research/train_research.py --data data/thyroidDF.csv --out reproduced_results
```

Активация окружения и изменение ExecutionPolicy не нужны. Если `py -3.12` не найден, установите Python 3.12 с официального сайта. Зафиксированы NumPy 2.3.5, pandas 2.2.3, scikit-learn 1.8.0. Фактическое окружение воспроизведения сохранено в `results/windows_verification.json`.

В `reproduced_results/` появятся метрики, матрицы ошибок, предсказания, разбиение, аудит фильтров, модель JSON и примеры. Обучение **не заменяет** модель интерфейса автоматически. Сначала сравните метрики и экспорт. Возможные расхождения следует исследовать, не подставляя заранее заданные контрольные числа.

## Проверка работы

Публичный репозиторий содержит ручной протокол, учебные файлы и результаты. Автоматические тестовые скрипты оставлены локально по запросу владельца и не включены в GitHub или переносимый ZIP.

Сначала пройдите демонстрационный сценарий с PDF и JPG, затем проверьте:

| Действие | Ожидаемое поведение |
|---|---|
| Расчёт без подтверждения | Требуется сверка |
| Удалён референс | Недостаточно данных, граница не подставляется |
| Нижний референс ≥ верхнего, отрицательное число | Просьба исправить данные |
| Значение `<0.01` | Не используется как точная концентрация |
| Несовместимая единица | Показатель не получает достоверный статус |
| Повтор заполненного показателя | Сообщение о дубликате |
| Изменение данных или контекста | Результат очищен, подтверждение снято |
| Возраст не указан, детский возраст или особое условие | Интерпретация ограничена |
| Низкий ТТГ, нормальный FT4, нет FT3 | Запрос свободного Т3 |
| Второй сервер | Другой свободный локальный порт |

В локальной рабочей копии исходные 24 проверки запускаются командой `node research/test_lab_core.cjs`. В свежем клоне GitHub этого скрипта нет. Для обычной работы Node.js не требуется.

Фактический протокол и непроверенные шаги: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Сборка переносимого ZIP

Из корня исходников, с установленным Python и интернетом:

```powershell
py -3 portable/build_windows.py --output .\build
```

Результат: `build/ThyroVision_LAB_Windows.zip`. Сборщик получает официальный CPython, сверяет SHA-256, добавляет приложение, модель, локальные библиотеки, датасет, результаты, методику, учебные файлы и инструкции. Пакеты pip не нужны. При несовпадении хеша сборка прекращается.

Для повторной сборки с уже скачанным официальным архивом:

```powershell
py -3 portable/build_windows.py --output .\build --runtime-archive C:\path\python-3.14.10-embed-amd64.zip
```

SHA-256 проверяется и для локального архива. Встроенный Python не хранится в Git-истории. OCR/PDF-ресурсы и модель находятся в `dist/assets/` и включены в репозиторий.

## Ограничения и данные

- OCR может ошибаться на других бланках, плохих фотографиях и сложной вёрстке. Успешный учебный пример не измеряет качество распознавания на выборке.
- Правила описывают лабораторный профиль, не назначают лечение и не устанавливают причину отклонения. Антитела сравниваются со своими референсами отдельно.
- Историческая ML-выборка отфильтрована и несбалансирована. Независимость пациентов train/test не доказана, внешняя клиническая валидация не выполнена. «Без комментария» не означает подтверждённого отсутствия заболеваний.
- Бланк находится во вкладке. Сервер раздаёт ресурсы и не принимает медицинские файлы. Браузер может кешировать общие языковые модели. JSON содержит введённые показатели, его хранение контролирует пользователь.
- Во встроенном браузере ChatGPT вызов печати зависал. Сохранение PDF в обычном Chrome/Edge остаётся пунктом ручной приёмки. JSON-экспорт проверен фактически.
