# Происхождение и перенос ThyroVision LAB

Исходник получен из существующего проекта Sites «ThyroVision LAB — разбор анализов щитовидной железы»: https://thyrovision-hashimoto-lab.breathtakingdart8.chatgpt.site .

- Опубликованная версия 3: коммит `6b3627ca3f8c33c8c47016135af54d5c94b4a48e`.
- Полученная вершина исходного репозитория: `27df54078a5d60fbc767d4f968bf3987b9bcb48c`, с подготовкой Windows-комплекта.
- Назначение: https://github.com/CryptoGu1/Thyroid_disease_prognosis .

Для GitHub подготовлен отдельный снимок LAB-кода. В него не включены тестовые скрипты по просьбе владельца, служебная привязка Sites, локальные окружения и прежний эксперимент `legacy/ultrasound`. Полный исходник и исходные тесты сохранены локально. Test-предсказания в `results/` являются результатами эксперимента, а не тестовыми скриптами.

## Изменения

1. Название показателя редактируется в строке. Изменение сбрасывает подтверждение и результат.
2. Тироксин и антитиреоидные препараты отмечаются отдельно. Условия входят в JSON и отчёт и ограничивают интерпретацию.
3. После смены показателя или единицы появляется напоминание о сверке чисел. Автоматического пересчёта нет.
4. Снятие подтверждения очищает результат. Повторный выбор файла запускает импорт снова. Несколько перетащенных файлов вызывают сообщение вместо молчаливого выбора первого.
5. Отчёт содержит источник, возраст, условия и время выполненного расчёта.
6. Эксклюзивное занятие порта в Windows устраняет повторное привязывание к занятому адресу, допускаемое SO_REUSEADDR.
7. Сборщик использует временную папку внутри каталога вывода, включает документацию, исключает тестовые скрипты и поддерживает локальный архив Python с проверкой хеша.
8. Проверка происхождения CSV в отчёте обучения связана с хешем ранее проверенного файла и не приписывается произвольному CSV.

Опубликованный сайт Sites не обновлялся. Изменения относятся к локальной версии и подготовленному снимку для GitHub.
