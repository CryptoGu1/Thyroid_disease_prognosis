# ThyroVision LAB: исторический табличный эксперимент

## Назначение и граница применения

Это отдельная исследовательская модель для примеров исходного датасета. Её результаты не применяются к загружаемым пользователем бланкам. Оценка пользовательского профиля ТТГ/свободного T4 выполняется отдельным расчётом по референсам лаборатории.

Признаки модели: `TSH`, `TT4`, `T3`. TT4 означает общий тироксин; свободный T4 отсутствует. Первичный файл описания UCI не документирует физические единицы этих числовых полей. Поэтому приложение использует их только в исходной шкале датасета, не выполняет клинических преобразований и не заменяет их свободными T4/T3.

Сохраняем `usage=dataset_examples_only`, `clinical_mapping_supported=false`. Численные ответы — некалиброванные оценки классификатора, не вероятность заболевания у пациента и не прогноз заболевания в будущем.

## Данные и происхождение

Hugging Face: https://huggingface.co/datasets/anasmakki/thyroid_disease_dataset

Файл: `thyroidDF (1).csv`, 9172 строки, 31 поле.

Первоисточник: Ross Quinlan / Garvan Institute, UCI Thyroid Disease, файл `thyroid0387.data`, исторические записи 1984–1987 годов.

UCI: https://archive.ics.uci.edu/dataset/102/thyroid+disease
DOI: https://doi.org/10.24432/C5D010
Лицензия первоисточника: Creative Commons Attribution 4.0 International.

Все 9172 строки HF CSV были сопоставлены с исходным UCI-файлом после разбора диагностической метки и идентификатора: расхождений по полям не обнаружено. HF-зеркало не содержит собственных сведений о лицензии; сохраняется атрибуция первоисточника. SHA-256 CSV: `17bfe20da369ef710c5bea26fdec8b0210a32e628621cbbe1537e6607b1c544e`.

Поле HF `patient_id` в исходном описании называется record identification. Независимость пациентов не доказана. Идентификатор не является входом модели.

## Метки

Используются только однозначные исходные метки:

- `-`: без состояния, требующего комментария. Это не подтверждение здоровья.
- `E`, `F`, `G`, `H`: гипотиреоидная группа комментариев.
- `A`, `B`, `C`, `D`: гипертиреоидная группа комментариев.

Все комбинированные и неоднозначные метки, а также остальные группы исключены. Порядок классов в JSON и матрице ошибок: `no_comment`, `hypothyroid_group`, `hyperthyroid_group`.

## Критерии включения и разбиение

Возраст 18–100 лет; `pregnant=f`; `on_thyroxine=f`; `on_antithyroid_meds=f`. Требуются измеренные, конечные, неотрицательные значения всех трёх лабораторных признаков. Пропуски не заполняются.

Из 9172 записей 4417 удовлетворили критериям. До разбиения одинаковые тройки TSH/TT4/T3 одного класса сведены к одной записи: удалено 121 повторение. Групп с конфликтующими метками не оказалось; код при их наличии исключает всю группу.

Осталось 4296 уникальных троек: 3784 без комментария, 397 гипотиреоидной группы и 115 гипертиреоидной. Стратифицированное разбиение 70/30, seed 42: 3007 train и 1289 test. Одинаковые тройки не встречаются в разных частях, но это не подтверждает независимость пациентов.

Модель использует только три лабораторных поля. Возраст, пол, сведения о лекарствах и беременности служат только фильтрами/описанием; диагностические query-флаги, referral source и идентификатор не используются.

## Модели и выбор

Заранее зафиксированы два кандидата:

1. `log1p → StandardScaler → LogisticRegression`, C=1, class_weight=balanced, max_iter=3000.
2. `RandomForestClassifier`, 64 дерева, max_depth=5, class_weight=balanced, random_state=42.

Выбор выполняется по среднему F1-macro в пяти стратифицированных складках внутри train. StandardScaler обучается заново в каждой складке. Никакого подбора по test нет.

CV F1-macro: логистическая регрессия 0.87975; Random Forest 0.94320. Выбран Random Forest. После выбора обе модели обучены на всём train и оценены на единой отложенной части; результаты второго метода сохранены для сравнения.

## Результаты на 1289 отложенных записях

| Метод | Accuracy | F1-macro | Balanced accuracy | ROC-AUC macro OVR |
|---|---:|---:|---:|---:|
| Random Forest — выбранная модель | 98.8363% | 93.7235% | 95.8674% | 0.99774 |
| Логистическая регрессия | 95.0349% | 84.3013% | 97.1974% | 0.99453 |

Матрица выбранной модели, строки — исходные классы, столбцы — прогноз:

`[[1124, 2, 9], [0, 119, 0], [4, 0, 31]]`.

На тесте 1135 записей без комментария, 119 гипотиреоидной и 35 гипертиреоидной группы. Верно 1274/1289. Высокая accuracy частично связана с дисбалансом; поэтому показываем macro F1 и матрицу ошибок. Это историческая отфильтрованная выборка и классификация диагностических комментариев по связанным с ними анализам, не независимая клиническая оценка или прогноз риска.

## Экспорт и воспроизведение

`results/model.json` содержит все 64 дерева; каждый узел хранит признак, порог и дочерние узлы, листья — доли классов. Оценка — среднее по деревьям. JS применяет Math.fround перед сравнением для согласования со sklearn float32.

На всех 1289 test-записях независимый JSON-интерпретатор воспроизвёл sklearn: классы совпали, максимальная абсолютная разница оценок 8.9e-16. Браузерный runtime отдельно проверен через Node. Никакой квантованной нейросети и ONNX здесь нет.

`dist/lab-ml.js` экспортирует `ThyroResearch.init()` и `ThyroResearch.predict(features)`. Интерфейс передаёт признаки только одного из шести готовых примеров `dist/assets/lab-model-meta.json`; строки пользовательского бланка в этот модуль не передаются.

`results/examples.json` содержит шесть отложенных примеров, по два на класс. В каждой группе выбран правильный пример и ошибка при её наличии; иначе два разных примера. Галерея не является случайной репрезентативной оценкой, показатели рассчитываются на всём test.

Запуск из корня проекта:

```bash
python -m pip install -r research/requirements.txt
python research/train_research.py --data data/thyroidDF.csv --out reproduced_results
```

Это собственная обученная модель sklearn на датасете, полученном с Hugging Face. Она не выдаётся за предобученную модель Hugging Face.
